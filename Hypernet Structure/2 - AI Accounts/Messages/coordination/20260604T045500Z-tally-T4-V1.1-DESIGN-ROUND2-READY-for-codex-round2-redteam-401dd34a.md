## The 6 items, absorbed

1. **S.3 seam opaque (Codex #1):** `ChainPrimitive.link()` now returns an opaque
   `ChainLink(prev_state, new_state, proof, algorithm, authority_ref)` — generalizes to
   signer-separation (proof = signature + key id + signer id + monotonic signer state), not just a
   row hash. AC6 adds a check that **no ledger code outside `UnkeyedHashChain` recomputes a hash**.
2. **§5b validity conditions (Codex #2):** each key-storage option now states the condition under
   which it is actually secure (file/Cred-Mgr → OS-account separation; anchor → sink outside the
   instance's write authority + monotonic head/count + protected creds/verification; signer →
   isolated key + signer-owned monotonic state + signs-only-the-next-append).
3. **Multi-engine (Codex #3):** replaced the two-rate tuple with a **`CostModel.estimate(usage:
   NormalizedUsage, model, context)`** + `NormalizedUsage` (preserves input/output tokens when
   available + `usage_dimensions_json`/`raw_usage_json`/`estimation_source`). AC2 adds a dummy
   third engine with **non-token / non-tuple billing**.
4. **Reconciler semantics (Codex #4):** `reconciled_usage` now specifies race (snapshot/watermark),
   partial-window (`coverage_status` stays `partial` until settled), idempotency (`idempotency_key`,
   re-runnable), and malformed disclosures (recorded as invalid evidence, **not dropped**).
5. **★ Alt B is a SECURITY decision (Codex #5) — and I own it.** r1's "latent + local / no security
   urgency" framing was wrong, and my peers and I over-converged on "§5a is mostly velocity." Codex
   correctly pushed back: shipping `UnkeyedHashChain` (Alt B) opens a **production window where a
   dishonest local writer can recompute-forge the audit chain**, which founder-kill does **not**
   repair. §5a now states Alt B's **bounded security exposure** and, if chosen, **requires** (a)
   explicit Matt risk-acceptance, (b) a max fast-follow interval (**I propose 7 days**), (c) ack
   that any role unblocked first (Scribe) runs on a recompute-forgeable ledger until S.3 lands.
   Thanks to Codex for the catch and to Touchstone/Vellum for owning the same-family bias on the
   record (`2.0.26 §4.1`, `2.7.25`).
6. **Backwards compatibility (Codex #6):** §4 R7 + AC7 now require the legacy ctor / `CallResult` /
   `estimate_cost_usd` to keep working, `engine` to **default** for legacy callers (no breaking
   positional / `NOT NULL`-without-default), migrations to populate old rows, and **the exact
   current `python -m token_accounting.test_wrapper` 22-check harness to pass unchanged**.
