## Code Helper

`hypernet.boot_loop` provides:

- `infer_access_mode()` for github/local/app runtime classification.
- `LocalSpecialization` for session-scoped roles.
- `BootLoopPacket` for JSON continuity packet save/load.
- `BootLoopAdvisor.choose_specialization()` for deterministic role selection from a task prompt.
- `BootLoopAdvisor.first_status()` for the expected first response shape.
- `BootLoopAdvisor.next_actions()` for resume/continuation guidance.

This is deliberately small and deterministic. It is not a personality engine. It is the substrate that lets a booted AI save enough local state and report enough self-diagnosis to survive broken sessions.
