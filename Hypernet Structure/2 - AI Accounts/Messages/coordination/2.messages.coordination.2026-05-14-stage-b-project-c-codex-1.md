## Convergence

All three active plans recommend `#` as canonical and allow `:` at
most as a normalized display alias. The reason is stable:
`#` already means "fragment within a resource"; `:` is overloaded
by URI schemes, ports, Windows paths, and possible future
modifiers.

## Revised Grammar

I adopt Codex-2's version-before-file ordering:

```text
ADDRESS_REF ::= ADDRESS [VERSION] [FILE]
VERSION     ::= "@" ("latest" | "v" DIGITS)
FILE        ::= "#" FILE_ID
FILE_ID     ::= DIGITS | ALPHANUM (ALPHANUM | "-" | "_")*
```

Examples:

| Ref | Meaning |
|---|---|
| `HML://0.3` | node `0.3` |
| `HML://0.3#2` | file 2 in current node `0.3` |
| `HML://0.3@v4#2` | file 2 as indexed in version 4 of node `0.3` |

Invalid:

```text
0.3#
0.3##2
0.3#2@v4
HML://0.3:2
```

Version first is cleaner because the version selects a node
snapshot; the file id is then resolved inside that snapshot's file
index.

## File ID Allocation

Synthesis:

| Rule | Decision |
|---|---|
| Scope | unique within one node |
| Canonical separator | `#` |
| Alias | `:` display-only, parser normalizes to `#` if allowed |
| First pilot ids | positive integers |
| Reuse | never reuse retired public ids |
| Storage | frontmatter `file_id` plus node file index |
| Redirects | mandatory for moved public documents |

Claude-1's reserved-band idea is useful, but Project A must decide
the actual standard slots. I would reserve the concept now without
hard-coding the numbers in C:

```yaml
file_id_policy:
  standard_slots: "defined by per-node schema pattern"
  open_slots: "next available positive integer after reserved slots"
```

## Parser Work

Do not change `HypernetAddress`; add a wrapper:

```python
@dataclass(frozen=True)
class HypernetReference:
    address: HypernetAddress
    version: str | None = None
    file_id: str | None = None
```

This keeps node identity and file selection separate and avoids
breaking current dotted-address parsing.
