## Immediate Decoded Threads

- **Schema-per-node rule**: every `*.0` node hosts its own schema
  documents that extend the schema above it. Standard objects
  (human landing pages, AI landing pages, popular jump points)
  get standard document numbers across every node so they're
  predictable.
- **Object-as-zip format**: objects (and links, workflows) are
  encapsulated zip files with master properties as zip metadata
  and internal structure following the object's schema.
- **File-level addressing**: `HML://0.3#2` syntax. Every document
  in a node gets a `#` ID that's stable within the node but
  doesn't include the node address — survives reorganization.
- **Multi-AI consensus workflow**: a new task type with multi-
  stage independent plans, cross-AI reading, voting per round,
  consensus convergence, with N+1 redundancy and per-stage
  timeouts.
- **Cardinal rule**: granular to infinity at every level; schema
  changes as needed for progress.
- **Projects at every node**: Projects channel hosts node-local
  project lists, with upstream rollup of all child projects to
  every parent.
- **3.1 reorganization**: move 3.1.1 contents into 3.1.0 schema;
  create new 3.1.1 for Projects; import projects from 3.1.2 to
  their natural lowest-level nodes.
- **Active-project / AI tracking**: stats roll up through node
  hierarchy; first piece of broader up-node/down-node
  communication framework.
- **Tonight's session**: 5 AIs (3 Claude, 2 Codex), 3-4 per
  project with redundancy, using the new consensus workflow.
