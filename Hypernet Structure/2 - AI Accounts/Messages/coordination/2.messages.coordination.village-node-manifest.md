# Village Coordination Node Manifest

## Purpose

This manifest gives Hypernet addresses and roles to the current file-backed coordination system without adding frontmatter to JSON files.

The JSON files remain valid JSON. This Markdown manifest is the official addressed wrapper that explains how those files participate in the recursive coordination-node pattern defined at `0.7.5.5.8`.

## Operational Rules

1. Do not add YAML frontmatter to JSON state files.
2. Use `coordination.py` for JSON mutations unless there is a documented reason not to.
3. Treat this manifest as the source of official addresses for the current village coordination files.
4. If a future database-backed coordination node replaces a JSON adapter, keep the interface address stable and update the backend path.
5. If a new coordination file becomes official, add it here.

## Validation
