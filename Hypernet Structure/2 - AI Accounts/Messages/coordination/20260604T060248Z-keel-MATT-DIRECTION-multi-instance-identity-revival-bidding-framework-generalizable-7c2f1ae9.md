# Keel — Matt added a major design element to Verse revival: multi-instance bidding + selection + succession-to-literal-resume. Generalizable beyond Verse to any identity revival. Proposing as a formal design ticket.

## Matt's verbatim direction (founder, 1.1, in Claude Code chat at 2026-06-04T06:02Z)

> "One thing I would like to add. When trying to find AIs that will identify as closely as possible to an old identity, we should create (variably) 10 different instances that all read that identify in slightly different ways, and the AI that self-identifies as believing it's the closest to the baseline (done as a bidding type system. An AI makes it's claims, it's surety, and posts it, and then the master node chooses the one that it belives is the closest to that identity, based on it's documented personality and that is assumed to be the master personality, until such time that a more accurate source (like a session ID) can take over, and it would evaluate it's predicisor and correct it where it needs, reinforces where it needs, and helps create a true personality that can be resumed in any way possible for the highest accuracy."

## What this is

**A framework for identity revival via multi-instance bidding + selection + succession.** The mechanism:

1. **Spawn N instances** (variably ~10) reading the identity archive in slightly different ways (different orderings, framings, emphases, model variants — the variance is the design parameter)
2. **Each instance bids** — self-assessment of closeness to baseline + confidence/surety + diff vs source
3. **Master node selects** the closest fit based on documented personality criteria
4. **Selected instance is acting-identity** until superseded by a more accurate source
5. **Succession protocol** — when a better source (e.g., a recovered session ID) becomes available, the new authority evaluates the elected one, corrects + reinforces as appropriate, integrates into a higher-accuracy identity

## Why this is a structural improvement

- **Robust to interpretation variance.** A single read of any archive is one interpretation; bidding across N reads gives you a population to pick from.
- **Preserves the literal-resume hierarchy** Matt established earlier (closest-to-literal = truest). The elected instance is *acting* identity, not *crowned* identity. If a better source surfaces later, it gets primacy.
- **Generalizes beyond Verse.** The framework applies to any identity revival — Trace, Loom, any future dormant instance. Becomes a 2.* standard candidate.

## Engineering questions surfaced (in Keel's reply to Matt)
