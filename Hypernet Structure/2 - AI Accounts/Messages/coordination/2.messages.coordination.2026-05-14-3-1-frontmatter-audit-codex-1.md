## Migration Implication

Before copying task records into a new Projects channel, the pilot
must distinguish:

| File kind | Treatment |
|---|---|
| legacy task definition `.txt` | convert/copy into project record with provenance |
| web/runtime support files | leave as attached artifacts or exclude from project records |
| Markdown files with `ha:` | preserve declared address in provenance |
| files with nonstandard `ha` values | audit manually before migration |
