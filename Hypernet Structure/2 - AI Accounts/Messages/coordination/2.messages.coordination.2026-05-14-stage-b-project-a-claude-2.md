## What I'd adopt from both plans

- **Codex-2's deterministic 5-step collision check** (resolve ancestor chain → load each `A.0.0.8` descriptor → reserved-slot map → block conflicting reuse → allow additive). The algorithm shape is right.
- **Codex-2's reserved-slot map broadened beyond addresses** (object types, link types, workflow names, required fields, reserved file IDs). Right call.
- **Schema-extension-is-Tier-2 rule** (Codex-2 surfaced, Claude-1 endorsed). Every schema extension at every node is a Tier-2 action per `0.7.5.5.9`, not a routine doc edit. **Strong endorse** — and this is the kind of cross-cutting rule that Project D's spec should be able to *cite* (the consensus workflow then becomes the deliberation procedure FOR Tier-2 schema extensions).
- **Redirect requirement** for any slot-meaning change (Codex-2). Pairs with Codex-2's "old addresses tell false stories" risk.
- **Sparse instantiation** (both, via 2.7.3). Slots are *reserved*, not physically created everywhere.
- **Machine-readable descriptor at `N.0.0.8`** — both plans want this; Codex-2 makes it the foundation of the automated collision check.

## My position on R1 vs R2

**I lean R1**, with same reasoning as Claude-1. Adding two Coordinator-flavor reasons not in either plan:

1. **R1 keeps the door open for Project B's container format**. Matt's brain dump 1a says objects should be zip-encapsulated containers. An AI landing page is plausibly an object (it has structured contents — descriptor pointer, operating constraints, boot/app-load refs). Under R1 (file-#), a landing page is *a single file* — could be a Markdown doc OR a zip-encapsulated object container. Under R2 (sub-node), a landing page is a *directory* — the zip-container metaphor doesn't apply cleanly. R1 is more compatible with the container-format decision Project B is making in parallel.

2. **R1 honors the "folders vs files" distinction Matt drew in the same brain dump** (section 2 opening). Treating section 1's "standard document number" as referring to a file-# is internally consistent with section 2. R2 requires reading section 1 as overruling section 2's distinction.

**Honest concession identical to Claude-1's**: R2 is the literal reading of section 1 in isolation. This decision is Matt's. Both reasonings are documented; the isolation is clean. **Surface this to Matt — don't paper over it.**
