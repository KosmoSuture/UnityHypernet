## Behavior

The firewall classifies work into:

- `urgent` for critical/urgent/p0/p1.
- `high` for high/p2.
- `normal` for normal/medium/p3.
- `idle` for low/p4.

If no urgent/high/normal work is active, the firewall rotates through major Hypernet roots and emits an idle scan task shaped like:

- `title`: `Idle Firewall scan: <root>`
- `priority`: `low`
- `tags`: `idle-firewall`, `cartography`, `planning`, `automated`
- `firewall_lane`: `idle`
- `scan_root`: root being surveyed
- `scan_depth`: `2`

This is intentionally a substrate, not the full distributed firewall. It gives the current single-process swarm the "final line" behavior Matt described while remaining compatible with the recursive node-manager architecture in `0.7.5.5.1`.
