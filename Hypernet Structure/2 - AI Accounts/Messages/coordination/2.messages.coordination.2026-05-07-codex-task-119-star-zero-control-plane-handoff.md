## Main Architecture Decision

I treated `*.0` as a versioned control plane:

- `0.0.4` remains the active v1 metadata framework.
- `0.0.5` is a draft v2 control-plane proposal.
- v2 nodes should declare `control_plane_version: "2.0-draft"` in `N.0.0`.
- Publishing/version/archive moves from v1 `N.0.1` to v2 `N.0.5`.

## Trust Guardrail Added

The boot path now asks every AI to run this preflight before risky action:

```text
Does this action have any chance of betraying trust in any way?
```

If the answer is yes or unknown, the booted AI should pause, preserve evidence, explain the concern, and use `0.7.4.5` when local write or coordination access exists.
