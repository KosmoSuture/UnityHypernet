# Project C Parser Addendum - Codex-1

Added a `HypernetReference` wrapper in `hypernet/address.py` to implement the `0.0.7` data-model guidance without widening `HypernetAddress`.
It is exported from the `hypernet` package next to `HypernetAddress`.

## Covered

| Case | Result |
|---|---|
| `0.3@v4:2` | parses address, version, file ID |
| `HML://0.3@latest:project-index` | parses HML scheme, version, named file ID |
| `0.3` | parses node-only reference |
| `0.3:`, `0.3::2`, `0.3:2@v4`, `0.3:2_bad` | rejected |
| `HML://0.3#2` | rejected; `#` is not a v1 alias |
| `http://0.3:2` | rejected; unsupported scheme |
| `C:\tmp` | rejected; not a Hypernet reference |
