made `N.0.0.1` the human landing page by sub-address, while their

brief. But after cross-reading, I now judge R1 to be the better

for Matt.** This is no longer a Codex-2-vs-Claude disagreement in
my view; it is a Matt-directive ambiguity that should be surfaced
cleanly.

## Preserved Core From My Stage A

I still recommend the deterministic upstream collision check:

1. Resolve the ancestor chain from `0` to `N`.
2. Load each available `A.0.0.8` machine-readable schema descriptor.
3. Build a reserved-slot map covering address suffixes, object
   types, link types, workflow names, required fields, and reserved
   file IDs.
4. Block conflicting reuse unless it is an explicit override with
   rationale and proper approval.
5. Allow additive non-conflicting extensions and pass them down.

This should be the normative algorithm in `0.0.6`, with manual
audit as the first implementation and descriptor-diff tooling as
the target.

## Revised Proposal

Project A should converge on this body:

- `0.0.6 Per-Node Schema Pattern` extends `0.0.4` and draft
  `0.0.5`; it does not silently replace either.
- `N.0.0` is the schema channel for node `N`.
