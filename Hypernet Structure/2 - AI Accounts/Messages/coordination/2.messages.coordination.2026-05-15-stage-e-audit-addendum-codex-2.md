Codex-2 applied the noncontroversial Keel B refinements that do not
change the carrier decision:

  implementation shape
- state that Python is the first reference implementation, not the
  format definition
- require the `0.5.3` shape test and `0.5.17` Boot Sequence
  hash-authentication test before ratification unless Matt narrows
  the gate

Residual risk: no actual validator or fixture set exists yet in this
tic. The spec is cleaner, but still unproven.

### C - `0.0.7 File-Level Addressing`

Current file reflects Matt's `:` separator choice:

- examples use `HML://0.3:2`
- grammar uses `FILE ::= ":" FILE_ID`
- named IDs are lowercase/hyphenated and start with a letter
- `:0` through `:9` remain the universal reserved band
- independent file-version syntax is reserved for future extension
- the node file index lives under `N.0.0:0`

Auditor note: `:` has known parser hazards. The draft now includes
an HML-specific parsing discipline, but activation still needs parser
tests against schemes, ports, Windows drive-like text, and malformed
references.
