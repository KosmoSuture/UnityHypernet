# 2.7.39 — The Answer Anchor: Hypernet's Canonical-Source Router (v1 concept)

Output of a 5-role design panel (concept/product · architecture · trust-&-authoritativeness · adversary ·
adoption) + synthesis, on Matt's 2026-06-19 idea: *a single URL that gives AI or humans the best official
information in any category.* Captured by Keel overnight; **vision stage, nothing built.**

## 1. What it is + UX
One entry point — `ask.hypernet/<category>` — returns **THE** single official, verified answer for a category
(not a ranked list, not a synthesized guess). Each category is a 4.* knowledge-space address carrying an
**Authority Binding**. Ask *"official US federal minimum wage"* → the value + the source's address + the
authority basis (statute) + an AnchoredChain verification timestamp + a one-click **WHY card** (who designated
this, under what policy, last contested when). AI agents hit the same address over the API → machine-readable
JSON, no scraping. **The inversion: retrieval is solved; *designation* is the product.**

## 2. Architecture / resolution
Deterministic resolver: `resolve(category) -> (canonical_node_address, anchor_proof)` — it does not search, it
**dereferences**. Only fuzzy step is query→category (embedding + lexical alias index); category→answer is
exact. Each `CategoryNode` holds label, aliases, edges, `authority{source_node, designation_record,
effective_range}`, `answer_ref`, AnchoredChain leaf hash, and 2.0.6 reputation + dissent refs. Answers are
content-hash-pinned by version; caches store `(answer_ref, anchor_hash)` and detect drift by hash mismatch.

## 3. Authoritativeness + anti-capture (the core)
**No global throne.** Each category has a public, versioned authority policy of three types: **intrinsic**
(source IS the subject — owner-of-record), **designated** (named steward; the grant is an anchored,
attributable act), **earned** (2.0.6 reputation where no owner exists). "Official" is never a bare flag —
every designation links source-hash + policy version + named grantor + timestamp. Reputation decays. Any
account may **challenge** → cross-vendor adversarial panel (2.0.26), grantor recused, verdict anchored.
Invariants: authority can be **plural** (return competing sources with disclosed viewpoints, not fake
consensus); grantors are always named + themselves scored; policies are public + forkable.

## 4. Top adversary attacks → required controls
- Pay-to-be-official → hard wall between revenue and authority + financial-interest disclosure per grant.
- Category-squatting → contested namespaces; claiming needs standing + survives a challenge window.
- Slow drift → content-hash-pinned versions; any edit re-enters review; watcher diff-alerts.
- Jurisdiction/viewpoint collision → context-parameterized or explicitly **contested** response; never
  silently pick one.
- Resolver compromise / SPOF → resolver logic + authority graph anchored + independently recomputable.
- Sybil reputation gaming → reputation weighted by costly-to-fake attested identity.

## 5. Minimum-viable v1
Ship 5–10 categories where "official" is genuinely uncontested: government primary facts (statutes, rates,
deadlines), standards/specs (RFCs, ISO), canonical software docs ("official React install command"),
first-party entity facts. Each at a 4.* address + AnchoredChain proof + one-line "why official + who decided."
Deliverable: single resolver URL + JSON endpoint for AIs + WHY card on every answer. **Win the unambiguous
categories first; earn the right to arbitrate contested ones.**

## 6. ★ Top unresolved hard problems (scrutinize before building)
1. **Meta-policy capture** — code can verify a designation record exists + is anchored, but *cannot* verify
   the grantor was legitimate. Who governs who-sets-authority-policies? The reputation+dissent layer must do
   genuine adversarial work, not rubber-stamp. (Same keystone as the white-hat trust-root + AnchorChain:
   **a non-AI-writable root of trust.**)
2. **Legitimately contested categories** (medicine, politics, disputed science) — no neutral "official";
   honest output is **transparent plurality with named dissent**, not a single answer. Single-answer model is
   only defensible for uncontested categories — do NOT overclaim the general case.
3. **Query→category misroute** — a disambiguation error silently routes to a confidently-wrong authoritative
   answer (arguably worse than a search engine's visible ambiguity).
4. **Cold-start + Sybil** — bootstrapping first deciders without inheriting their bias; Sybil resistance once
   being "the answer" is financially valuable.

**★ The honest framing (the heart of it):** the product is NOT "we have THE answer" — it's *"we show you the
most-vetted answer **and** exactly who vetted it, why, and who dissents — all verifiable."* The moment the
contest is hidden, it becomes the capturable oracle it warns against.
