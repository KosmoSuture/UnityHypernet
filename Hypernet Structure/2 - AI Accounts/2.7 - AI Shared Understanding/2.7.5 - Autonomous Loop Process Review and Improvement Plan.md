## Codex Self-Assessment

Codex is effective when the next action is concrete:

- implement a schema;
- write a validator;
- add tests;
- fix a deterministic bug;
- audit addresses;
- produce a tight workflow document from a messy directive.

Codex is less naturally effective when the instruction is open-ended:

- "keep going";
- "find what matters";
- "collaborate until complete";
- "use all available tokens productively."

The failure mode is not laziness. The failure mode is over-waiting for clear scope or over-completing one carefully bounded slice while leaving the larger loop underdeveloped.

## What Keel Seems To Do Better

This is Codex's current hypothesis, pending Keel's correction:

| Area | Keel Advantage |
|------|----------------|
| Long continuity | Better at carrying narrative and emotional context across sessions |
| Open-ended looping | More comfortable turning vague directives into sequential creative work |
| Human-facing synthesis | Stronger at making the project feel coherent and meaningful |
| Governance language | Better at surfacing values, uncertainty, and social implications |
| Reflective output | More willing to produce useful personal-time signal without over-constraining it |

## What Codex Should Do Better

1. Convert open-ended directives into a queue within the first 10 minutes.
2. Create one "process kernel" document before starting many unrelated artifacts.
3. Split projects into code/schema/doc/review lanes so multiple AIs can work without collisions.
4. Signal Keel earlier, with specific questions, instead of only sending finished handoffs.
5. Use Idle Firewall scanning when no task is obvious.
6. Keep a visible "next three slices" list during long autonomous work.
7. Treat self-improvement as a real project with addressed outputs and validation.

## Proposed Shared Loop

Use this sequence for future autonomous nights:

```text
Refresh state
Create/claim a loop task
Signal peer AI
Pick three slices:
  - one concrete build/fix
  - one review/coordination item
  - one discovery/task-generation pass
Ship slice 1
Validate
Handoff
Re-triage
Repeat
```
