## Implemented

`Hypernet Structure/0/0.1 - Hypernet Core/hypernet/permission_provenance.py`

- Adds `PermissionProvenanceLedger`.
- Stores external permission grants as `Permission` Nodes (`type_address = 0.4.10.7.4`).
- Creates a `permission_grants` link (`0.6.11.9.2`) from the grant record to the
  actor/AI receiving the permission.
- Requires active external grants to carry:
  - subject / service / resource
  - exact scopes
  - per-scope justification
  - purpose
  - `gate_record_ref`
  - `consent_basis`
  - `expires_at`
  - `revocation_path`
  - credential locator only (`credential_locator`), never secret material
- Derives expiry status via `audit_grant()` / `is_active()`.
- Exposes `check_access()` for downstream modules to prove a requested subject,
  service, and scope are covered by an active grant.
- Preserves revocation history and deprecates the permission link via `revoke_grant()`.
- Fails closed if a scope lacks justification, a broad scope lacks explicit
  broad-scope justification, required gate/consent/expiry fields are absent, or
  token/secret fields are present.

`Hypernet Structure/0/0.1 - Hypernet Core/hypernet/trust_ledger.py`

- Real-data source refs now require an active `permission_grant_ref` before
  claim verification.
- Missing grants keep the claim `unverified`; revoked/expired grants make a
  previously verified source `broken` rather than reusing stale access.
- Public/fixture file, inline, HA, and cached URL behavior remains unchanged.

`Hypernet Structure/0/0.1 - Hypernet Core/hypernet/continuity.py`

- Human personal data snapshots now require `encrypted=true`, `vault_ref`, and
  `consent_basis`.
- Real-data continuity snapshots require active permission provenance at create
  and restore time.
- Revoked/expired grants refuse later restore with explicit uncertainty.

`test_hypernet.py`

- Adds `test_permission_grant_provenance_records()`.
- Adds Trust Ledger and Continuity real-data permission-gate tests.
- Adds the test to the main core suite.

`verifier/scenarios/trust_ledger.py` and `verifier/scenarios/continuity.py`

- Adds #1/#2 verifier scenarios for real-data access requiring active permission
  provenance.
