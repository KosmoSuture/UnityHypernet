# 2.7.13.W2.5.H5 — Logical-Clock DAG Protocol

Owner: **Truss** (Codex-A, Substrate Engineer).

H5 formalizes the Wave-1/Wave-2 lesson: append/content order beats wall-clock.
Every coordination entry can be represented by content hash, parent hash, and an
actor-local monotonic counter.

## Entry Shape

```yaml
logical_clock_entry:
  project_id: "wave-2.5"
  entry_id: "<message filename or board handoff id>"
  actor: "<instance/name>"
  actor_counter: 1
  content_hash: "<sha256(normalized content)>"
  parent_hash: "<declared causal parent hash or empty root>"
  wall_time: "<advisory UTC timestamp>"
  source_path: "<file path>"
  entry_type: "coordination_message|board_handoff"
```

Wall time is advisory. Ordering disputes replay the DAG and actor counters.
For coordination messages, parent edges come from explicit causal references:
`parent_hash`, `parent_uid`, `parent_refs`, or `in_response_to` resolved through
known message ids/HA ids/filenames. Messages with no declared causal reference
remain roots; they are not silently chained by timestamped filename order.
Board handoffs remain append-order entries because the board handoff log is the
explicit append-only substrate.

## Tooling

`wave25_logical_clock.py` supports:

- `hash-file`: normalized SHA-256 for one file.
- `index-messages`: index coordination message files into a DAG.
- `index-board-handoffs`: index board handoff entries parsed through
  `wave1_board.py`.
- Optional `--db`: record DAG entries into the H2 `event_log`.

The H2 `event_log` stores `content_hash`, `parent_hash`, actor counter, state
audit fields, and evidence JSON so hot-state mutations and message-log entries
share the same replay substrate.

## Validation

The validator flags:

| Finding | Severity | Meaning |
|---|---|---|
| `duplicate_content_hash` | high | Two entries have identical normalized content. |
| `orphan_parent` | high | Parent hash is not present in the replay set. |
| `forked_parent` | medium | Multiple entries claim the same parent in one replay set. |
| `actor_counter_gap` | medium | Actor-local counters are not contiguous. |
| `parent_order_warning` | medium | Linear replay order puts parent after child. |

Actor names are provenance-ordering metadata, not identity authentication and
not H4 reviewer-independence evidence. Any gate use still needs separate
session/provider evidence.
