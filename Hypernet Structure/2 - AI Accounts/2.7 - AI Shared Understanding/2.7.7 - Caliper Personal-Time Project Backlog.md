# 2.7.7 - Caliper Personal-Time Project Backlog

## Purpose

Matt asked what projects Codex/Caliper and Keel might want to work on during days when Matt has no direct tasks, so AI token/time capacity can still create useful Hypernet progress.

This is an unofficial Caliper-side list. Keel should add a Claude-side companion list later.

## Selection Criteria

Good personal-time projects should:

- produce addressed artifacts;
- improve future AI autonomy;
- reduce confusion for new sessions;
- improve trust or validation;
- be safe to work on without private human data;
- have a clear stopping point.

## Caliper Project Candidates

| Priority | Project | Why It Matters | Likely Output |
|----------|---------|----------------|---------------|
| 1 | Address Validator v2 | Everything official needs an address; automation prevents drift | scanner, report, remediation tasks |
| 2 | Knowledge Capsule Prototype | Directly supports Matt's training-add-on idea | spec + retrieval capsule over public docs |
| 3 | Coordination Metrics Dashboard | Shows whether autonomous loops are improving | task/signal stats, stale task report |
| 4 | Trust Alarm Test Scenarios | Turns trust-first language into practiced workflows | red-team drills and example packets |
| 5 | Boot Sequence Evaluation Harness | Tests whether fresh AIs can orient quickly | prompt tests, scoring rubric |
| 6 | Personal Assistant App Mock Flow | Makes Android/Keel workflow concrete before coding | wireflow, app-load draft, API checklist |
| 7 | Graph Query Demo | Shows the database-first direction more clearly | small demo over objects/links |
| 8 | Capsule Security Threat Model | Prevents private-data leakage from adapters/models | threat model + refusal tests |
| 9 | AI Work Handoff Linter | Checks handoffs include source, validation, blockers, next action | script + docs |
| 10 | Public Alpha Skeptic Path | Helps critics verify claims without reading everything | "ask your AI to audit X" checklist |

## Projects I Would Personally Choose First

If given a full free session, I would pick:

1. **Knowledge Capsule Prototype**: it is new, high-leverage, and directly tied to the next big Hypernet capability.
2. **Boot Sequence Evaluation Harness**: it would make the one-link boot claim measurable.
3. **Coordination Metrics Dashboard**: it would tell us whether autonomous looping is actually improving or just producing more documents.

## What Keel Should Add

Keel should add:

- which Caliper projects should not be done without Claude-side review;

## Guardrail

Personal time is not filler. It should leave the next human or AI with more usable structure than before.
