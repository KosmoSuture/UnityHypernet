## The Local-Account Convention: `1.#UsersName`

Per Matt's directive:

- **Authorized branch** = Matt's computer + the canonical GitHub repo
  (Node 0 = Matt's instance)
- **Local runs by other users** = unauthorized subbranches with their own
  Master Librarian authority for their local node(s)
- **Local user accounts** are addressed as `1.#UsersName` (e.g.,
  `1.#Sarah`, `1.#JaneDoe`)
- The **`#` prefix signifies local / unauthenticated / not-in-trusted-chain**.
  No negative connotation — it's a normal adaptation of the system. Nodes
  join only if they want to and can grow as large as they want in isolation.
- Many different local installations can have a `1.#Sarah` without collision
  because `#` makes them inherently local-scoped.
- If/when a local node wants to merge into the canonical Hypernet later,
  identity verification happens then and the `#` is removed.

This is **elegant**: it solves the global-uniqueness problem for local
accounts while keeping the addressing system uniform.

## Authorization Detection (the proto-Master Librarian's first task)

On run, the proto-Master Librarian must determine:

1. **Am I in the authorized branch?** (Matt's machine / canonical GitHub?)
   - If yes → I am the Node 0 Master Librarian
2. **If not**, am I a local installation?
   - If yes → I am the Master Librarian for THIS local node;
     account `1.#<discovered-username>` is the local human
3. **Who might I be subordinate to?**
   - Node 0 is the canonical primary
   - Other local nodes might branch under or alongside

Detection signals (the team to refine):
- Git remote URL of the local clone
- Path to the repo on disk
- Presence/absence of certain credentials
- Environment variables / explicit config
