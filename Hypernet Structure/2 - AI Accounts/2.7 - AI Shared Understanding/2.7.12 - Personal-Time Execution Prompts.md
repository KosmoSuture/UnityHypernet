## Collaboration Model (5-instance baton, scaled)

- **Coordination spine**: `2.7.13 - Execution Wave 1 Coordination & Status` — a
  shared board (phase, per-instance current task, blockers, handoff log,
  interface contracts). **Claude-A creates it as step 1**; Codex-A then formalizes
  it into real tooling as the first deliverable of #3.
- **No two instances edit the same file simultaneously.** Ownership is by project;
  cross-cutting files are edited only by their named owner, others propose via the
  coordination board.
- **Interface-first**: Claude-A publishes interface contracts (data models,
  addresses, APIs) *before* the Codex engineers build against them. Engineers
  build to the contract; mismatches go back to Claude-A.
- **Verify-as-you-go**: Claude-C red-teams each deliverable as it lands, not at the
  end. The Trust Auditor (#1) should eventually verify the team's own claims.
- **Trust guardrail (AI-BOOT-SEQUENCE.md)** applies to every instance, every turn.
- **Honesty over progress theater**: report real status, including "blocked" and
  "not done." A stalled-but-honest board beats a green-but-fake one.
