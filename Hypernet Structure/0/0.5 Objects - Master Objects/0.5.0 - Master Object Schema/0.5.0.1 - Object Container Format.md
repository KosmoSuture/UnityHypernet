# Object Container Format - Codex-1 Implementation Notes

## Status

Superseded implementation draft produced from the 2026-05-14
Project B consensus loop. The canonical Project B draft is:

`Hypernet Structure/0/0.5 Objects - Master Objects/0.5.0 - Master Object Schema/0.5.0.1 Object Container Format.md`

This file is preserved as evidence and implementation notes. It no

## Principle

A Hypernet object package has one logical layout and two carriers:

| Carrier | Role |
|---|---|
| `.hno/` directory | canonical authoring and public review form |
| `.hno.zip` archive | deterministic transport, release, and archival form |

The zip is generated from the directory. It is not hand-authored.

## Directory Layout

```text
<object>.hno/
  manifest.yaml
  manifest.canonical.json
  schema/
    schema.json
  content/
  links/
    links.yaml
  provenance/
    history.yaml
  evidence/
  signatures/
  assets/
  checksums.sha256
```

Required for every package:

| Path | Requirement |
|---|---|
| `manifest.yaml` | authoritative human/repo manifest |
| `manifest.canonical.json` | generated canonical projection used for parser and hash checks |
| `schema/schema.json` | resolved schema references |
| `provenance/history.yaml` | creation and migration history |
| `checksums.sha256` | checksum for every non-directory member except itself |

## Manifest Minimum

```yaml
container:
  format: "hypernet-object-container"
  version: "0.1"
identity:
  address: ""
  object_id: ""
  object_type: ""
  version: "0.1.0"
  schema_refs: []
metadata:
  created:
    timestamp: ""
    by: ""
  modified:
    timestamp: ""
    by: ""
  status: "draft"
  visibility: "public"
access:
  owner: ""
  permissions: {}
integrity:
  hash:
    algorithm: "sha256"
    value: null
    scope: "content"
  verified: false
```

`manifest.yaml` is the source of truth. `manifest.canonical.json`
is generated from it using sorted keys, LF line endings, UTF-8, and
no BOM. Hash computation follows `0.5.0`.

## Zip Rules

The `.hno.zip` transport form MUST be reproducible:

| Rule | Requirement |
|---|---|
| member order | lexical |
| paths | relative, normalized, no absolute paths, no `..` |
| timestamps | normalized from manifest, not pack time |
| permissions | normalized |
| compression | deterministic settings |
| zip metadata | mirror only `ha`, `object_type`, `schema_ref`, and manifest hash |

If zip metadata and `manifest.yaml` disagree, validation fails.

## Validation

| Check | Level |
|---|---|
| required files exist | error |
| manifest has required `0.5.0` sections | error |
| link packages include source, target, relationship, and lifecycle status | error |
| workflow packages include trigger, steps, roles, and audit | error |
| every package member has a checksum entry | error |
| generated canonical JSON matches YAML manifest | error |
| zip metadata summary matches manifest | error |
| zip contains absolute path, `..`, symlink, or unsafe path | error |
| zip exceeds configured size or compression-ratio limits | error |
| binary asset lacks provenance or evidence reference | warning |

## Identity Boundaries

| Identifier | Meaning |
|---|---|
| `ha` | object identity in the Hypernet graph |
| `N#file_id` | locator for a plain file inside a node |
| `integrity.hash` | content equality marker |
| internal package path | member path inside one package |

A file promoted into an object package leaves the public
`N#file_id` namespace through a recorded migration. Package members
do not receive global file-level addresses.
