# Codex Cross-Vendor Review → v1.1 Hardening

The workflow was itself run through a cross-vendor review (Codex/gpt-5.5) — the same independence principle it
preaches. Codex found real holes; v1.1 resolves them. (Note: Codex first burned its whole budget trying to
*actually verify* the placeholder citations via web search — an accidental but real demonstration that live
verification is slow and can loop → hence the Verifier "verification budget + fail-to-human" rule.)

## CRITICAL findings → resolutions
1. **QA could trust the Verifier's table instead of rechecking sources.** → Role 8 must require attached
   source artifacts (excerpt/URL/ID + exact quoted support + date-checked) and independently re-spot-check a
   sample before anything is called "verified."
2. **Editor (role 7) runs AFTER verification → can silently break the cite↔claim match.** → Editor may not
   alter any verified legal proposition or citation text; ANY substantive edit re-triggers citation+fact
   verification on the changed passages. (Pipeline ordering fix.)
3. **"Authority exists" was checked separately from "this exact quote/pinpoint supports THIS sentence."** →
   Verify at the PROPOSITION/QUOTE/PINPOINT level, not just the citation level. (Applied to Role 3.)
4. **"Removed or flagged" still let bad authority ride along in the "clean draft."** → A clean draft may
   contain NO unverified authority; unresolved items appear INLINE and BLOCK "ready" — they are not buried in
   a report.
5. **Currentness / negative-treatment (overruled/superseded) under-specified.** → Separate required fields:
   current? controlling? not-overruled/superseded? jurisdiction-correct? — each with source proof.

## HIGH findings → resolutions
6. **Automation-bias risk** from "minimal oversight," green checks, "READY FOR ATTORNEY REVIEW." → Reframed:
   output is an **"AI-prepared draft for attorney review"** (no certification language). The attorney must
   sign off on a sampled set of citations + key facts + ALL judgment calls. "Minimal oversight" = *targeted*,
   never *reduced responsibility*.
7. **Verification Report can hide non-flagged errors.** → Add a mandatory EXCEPTION LOG + a RANDOM AUDIT SET
   of verified citations/facts the attorney must personally spot-check each time.
8. **Brady/Giglio only "surfaced."** → New **G7 Disclosure-Duty gate**: record-search scope, candidate
   disclosure items, deadlines/status, attorney decision log. Enforced on every applicable doc.
9. **Candor (RPC 3.3) not operationalized.** → New **Candor check**: no misleading omissions, no overstated
   holdings, no unsupported inferences, and adverse controlling authority is escalated, not hidden.
10. **Victim-rights named but not gated.** → New **Victim-Rights checklist gate** (notice, consultation,
    confidentiality/redaction, restitution/input, timing) before filing/service.
11. **Cross-vendor concurrence may be correlated** (same draft/snippets/premise). → Require INDEPENDENT source
    retrieval, blinded verification where feasible, and disagreement ANALYSIS — not vote-counting.

## MED findings → resolutions
12. **Confidentiality advisory only.** → Matter classification + approved-tool list + retention/no-training
    terms + redaction rules + audit log; **no cloud use for restricted materials** (local models only).
13. **UPL risk.** → Operation/release restricted to attorney-supervised users; every output labeled
    "draft work product requiring attorney legal judgment."

## Codex's single most important change
"No clean draft may contain unverified legal authority; unresolved items must appear inline and block
'ready'" — combined with verifying at the proposition/quote/pinpoint level (not just that the case exists).

## Net
v1.1 raises the workflow from "good assistant" to "safe enough for a working prosecutor to rely on with
targeted oversight" — the gates now ENFORCE the duties (disclosure, candor, victim rights), verification is
proposition-level with source artifacts, the editor can't break verified law, and the framing actively resists
automation bias. The 6 gates become **8** (add G7 disclosure-duty, G8 candor) + the victim-rights checklist.
