# Legal Workflow — Document-Type Playbooks

Per-document checklists the pipeline must satisfy (the Issue-Spotter loads the relevant one into the Plan;
the Compliance role verifies it). **All statute/rule references below are PLACEHOLDERS to be VERIFIED by the
Citation role against current Colorado authority — do not rely on them as stated.** [VERIFY-CO]

## How to use
For each document, the Element/Component checklist becomes the G3 (element) gate. The pipeline cannot pass G3
until every box is satisfied or explicitly flagged for the attorney.

---

### A. Criminal Complaint / Information (charging document)
- [ ] Correct caption: court, county, People of the State of Colorado v. Defendant, case no.
- [ ] Each COUNT states the offense, the statute (C.R.S.) [VERIFY-CO], and the date/place range.
- [ ] EVERY ELEMENT of each charged offense is alleged (Compliance role lists elements from the statute).
- [ ] Mental state (culpable mental state) alleged where required.
- [ ] Facts (or affidavit) establish probable cause for each element.
- [ ] Sentence-enhancement / habitual / crime-of-violence allegations pleaded if applicable.
- [ ] Speedy-trial / statute-of-limitations checked. Charging discretion noted for attorney.
- ⚠️ Attorney judgment: charge selection, count structure, enhancements.

### B. Motion (generic) / Response
- [ ] Correct caption + title + relief requested.
- [ ] Legal standard for THIS motion stated and cited [VERIFY-CO] (e.g., suppression, in limine, compel).
- [ ] Each required element of the standard argued and tied to record facts.
- [ ] Anticipated counterarguments addressed (from Adversary role).
- [ ] Proposed order attached if local rules require.
- [ ] Certificate of service + conferral (if required) present.
- [ ] Deadline/timeliness verified.

### C. Suppression Response (4th/5th/6th Am.)
- [ ] Identify exactly what defense seeks to suppress and on what theory.
- [ ] Standing analysis. Burden allocation stated correctly.
- [ ] Each exception/justification argued with record support (warrant, consent, exigency, inevitable
      discovery, good faith, etc.) [VERIFY-CO].
- [ ] Miranda/voluntariness if statements at issue. Attenuation if applicable.
- [ ] Every factual assertion record-cited (Record Checker).

### D. Plea Agreement
- [ ] Charges of conviction + dismissed counts stated precisely.
- [ ] Sentence terms / stipulations / caps; restitution; victim-rights compliance (VRA) [VERIFY-CO].
- [ ] Advisement of rights waived; immigration/collateral consequences advisement.
- [ ] Factual basis sufficient for each element of the plea count.
- ⚠️ Attorney + victim consultation required; this is judgment-heavy — flag prominently.

### E. Sentencing Memorandum
- [ ] Offense + conviction posture; presumptive/aggravated range cited [VERIFY-CO].
- [ ] Aggravating/mitigating factors tied to record.
- [ ] Restitution, fees, conditions; victim impact (VRA) addressed.
- [ ] Any mandatory minimums / sex-offense / crime-of-violence provisions verified.

### F. Subpoena / Discovery Certificate
- [ ] Correct form, issuing authority, service method, return date.
- [ ] Scope proper; privilege/relevance considered.
- [ ] Discovery: completeness + BRADY/GIGLIO disclosure obligations affirmatively checked (Record Checker).
- ⚠️ Brady is a constitutional duty — the Record Checker MUST surface exculpatory/impeachment material every time.

---

## Cross-cutting gates for EVERY document
- G1 Citations 100% verified (no [UNVERIFIED] survives to the attorney).
- G2 Facts record-cited or flagged.
- G3 This playbook's element checklist satisfied.
- G4 Adversary findings resolved/surfaced.
- G5 Caption/format/deadline/service correct for the court.
- G6 Two-model concurrence.
- ⚖️ Prosecutor-specific: Brady/Giglio review + victim-rights (VRA) considered on every applicable doc.
