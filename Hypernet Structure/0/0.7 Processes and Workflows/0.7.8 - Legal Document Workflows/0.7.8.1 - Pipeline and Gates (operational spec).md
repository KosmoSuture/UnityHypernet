# Legal Workflow — Operational Spec (how to actually run it)

The full 8-role pipeline is the gold standard, but you scale effort to stakes. **Always-on rules regardless
of tier:** the Citation Verifier runs on a *different* model than the Drafter, and **no document reaches the
attorney with an [UNVERIFIED] citation.**

## Tiers (pick by stakes)
| Tier | Use for | Roles run | Models |
|------|---------|-----------|--------|
| **Lite** | routine/low-stakes (simple subpoena, boilerplate) | 2 Draft → 3 Citations → 8 QA | ≥2 vendors |
| **Standard** | most motions/responses | 1 Plan → 2 Draft → 3 Cite + 4 Facts + 6 Compliance → 5 Adversary → 8 QA | ≥2–3 vendors |
| **Full** | charging docs, suppression, pleas, sentencing, anything contested | all 8 roles, parallel checks | ≥3 vendors |

Even **Lite** keeps the two non-negotiables: independent citation verification + a final QA gate + attorney sign-off.

## Running it MANUALLY (the attorney, today — no infrastructure)
1. Open the role prompts (`0.7.8.2`). Decide tier.
2. **Model A** session: paste Shared Rules + Role 1 (Plan), then Role 2 (Draft). Save the draft with its
   `[CITE: ]` / `[REC: ]` placeholders.
3. **Model B** session (different vendor, web/tools ON): paste Role 3 (Citation Verifier) + the draft →
   get the citation table; remove/flag anything UNVERIFIED. Run Role 4 (Facts) + Role 6 (Compliance) here too.
4. **Model B or C** session: Role 5 (Adversary) → fix or accept-with-reason.
5. **Model A or QA model**: Role 8 (Final QA) → clean draft + Verification Report.
6. **You** review the Verification Report, make the flagged judgment calls, and sign.

## Running it AUTOMATED (Hypernet swarm — optional, later)
Map each role to an `sm` worker on a chosen engine/model (see `session_manager/roster.json` pattern), run the
parallel checks as a fan-out, and gate with the same 6 gates the cross-vendor governance (2.0.26) already uses.
A "legal-doc" pipeline script would: Plan → Draft → parallel{Cite,Facts,Compliance,Adversary} → QA+concurrence
→ emit clean draft + Verification Report to a review folder. (Build only if volume justifies it.)

## The 6 gates (enforced before attorney review)
G1 Citations 100% verified · G2 Facts record-cited/flagged · G3 Element checklist satisfied (playbook) ·
G4 Adversary findings resolved/surfaced · G5 Caption/format/deadline/service correct · G6 Two-model concurrence.
A gate failure does NOT silently pass — it's listed at the top of the Verification Report as "NEEDS ATTORNEY."

## Metrics to watch (is it actually efficient + accurate?)
- Citation hallucination rate caught by Role 3 (should be >0 early — proves the gate works).
- Attorney edit rate / time-per-document (should fall as trust builds).
- Any error that reached the attorney → feed back into the role prompts (continuous improvement).
